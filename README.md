# Spark Weft

Full-colour Python 3 neon loom-shuttle arcade for [ElbowOS](https://x.com/ElbowOS).

Steer the shuttle across five glowing warp lanes. Bind matching weft sparks with Space. Dodge hot snags. Combo stitches for score.

## Play

```bash
pip install -r requirements.txt
python3 spark_weft.py --play
```

Controls: Left / Right (or A / D) change lane. Space / Up / W binds a stitch. R resets. Esc quits.

## Record a 9:16 reel

```bash
python3 spark_weft.py --record
```

Writes a 15s 1080x1920 H.264 MP4 (dummy SDL video driver, 30 fps).
